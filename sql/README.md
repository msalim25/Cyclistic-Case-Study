# SQL Folder

This folder contains all SQL scripts used for data cleaning, transformation, and analysis in BigQuery.

## Files
- **combine_tables.sql** — Merges all 12 monthly datasets into a single unified table.
- **data_cleaning.sql** — Removes duplicates, filters invalid trips, and standardizes fields.
- **analysis_queries.sql** — Queries used to generate insights, metrics, and visualizations.

## Environment
All SQL was executed in **Google BigQuery** using the public Divvy dataset.

## Notes
Scripts are modular and can be run independently or sequentially depending on your workflow.
