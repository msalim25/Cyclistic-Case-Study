# Data Folder

This folder contains sample data, reference files, and documentation related to the Cyclistic Bike Share Analysis project.

## Contents
- **sample_2022_divvy_tripdata.csv** — A small representative sample of the Divvy trip dataset.
- **schema.md** — A description of the dataset fields and data types.
- **notes.md** — Any additional data-related notes or transformations.

## Source Dataset
The full dataset is publicly available here:

[Divvy Trip Data](https://divvy-tripdata.s3.amazonaws.com/index.html)

This dataset includes:
- Ride timestamps  
- Start & end stations  
- Rider type (member vs casual)  
- Bike type  
- Trip duration  
- No personally identifiable information (PII)
